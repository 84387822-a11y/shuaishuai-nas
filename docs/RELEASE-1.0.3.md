# NAS助手 v1.0.3

面向飞牛 fnOS 的本地运维工具箱。本次是一个较大的版本跨越：补齐运维页面、统一视觉、修复若干误报。

## 新增页面
- **一键体检**：磁盘空间、内存、负载、硬盘 SMART、Docker 容器状态，按「正常 / 注意 / 异常」列出问题。
- **系统清理**：扫描 Docker 悬空镜像、构建缓存、已停止容器、7 天前的系统日志与临时文件；整卡勾选、安全项默认选中、清理前二次确认。
- **网络诊断**：连通性（DNS + TCP 时延）、**带宽测速**（实时仪表盘与曲线、上下行峰值、延迟/抖动/丢包，支持双向/仅下行/仅上行）、流量统计、路由追踪、局域网设备。
- **安全防护**：只读检查 SSH 配置、空密码/UID 0 账号、对外高危端口、防火墙状态与失败登录，给出评分与建议。
- **服务进程**：CPU/内存 Top 进程、启动失败的服务、监听端口；结束进程有保护名单。
- **Docker 治理**：容器启停重启、日志查看、镜像清单与磁盘占用。
- **硬盘存储**：磁盘型号、类型、容量、温度、SMART 健康，分区占用条。
- **文件管理**：存储卷用量、按类型空间构成、目录浏览、大文件排行；全程只读。
- **关于**：产品介绍、微信群/支付宝/QQ 群、版本检测与 Releases 入口。

## 改进
- 界面改为**浅色主调**并整体规整：去阴影去渐变、统一边框与留白、数字与留白比例统一。
- 左侧导航按「运维 / 系统」分组；「应用中心」移至运维分组末尾。
- 设置页重做：保留**外观（主题）**，新增**默认首页、紧凑模式、操作二次确认**。
- 应用介绍与关于页文案与当前功能对齐。

## 修复
- 浅色主题下主按钮白底白字（按钮文字看不见）。
- 暗色主题下「请我喝杯 8+1」卡片浅底浅字。
- 硬盘健康被误判为「异常」（把 `open device failed` 当成 SMART 失败）；现只解析健康结论行，读不到显示「未知」。
- 文件管理不再强制先授权：未授权时自动以存储卷（`/vol*`、`/home`、`/mnt`、`/media`）作为只读浏览根。

## 移除
- 「网络工具」页面（能力并入「网络诊断」）。
- 「硬件信息」页面。
- 「应用市场」（聚合第三方源）——保留原有「应用中心」。

## 安装
1. fnOS 应用中心 → 手动安装 → 选择 `.fpk`
2. 安装包：`shuaishuai_1.0.3_x86.fpk` / `shuaishuai_1.0.3_arm.fpk`
3. 要求 fnOS ≥ 1.2.1102

## 说明
全部功能在本机运行，不上传数据、零第三方依赖。清理、停止容器、结束进程等操作默认需要二次确认（可在设置中关闭）。文件浏览与统计仅限授权目录或存储卷之内，且为只读。
